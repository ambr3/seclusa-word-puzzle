# Seclusa Word Puzzle

Offline Seclusa word games in one PWA. **Puzzle** (Classic / Rush / Zen / Challenge) plus Ladder, Scrabble, Guess, and Blanks.

No clues, no accounts, no network after load (`connect-src 'none'`).

**Version:** 0.4.0  
**Source:** [github.com/ambr3/seclusa-word-puzzle](https://github.com/ambr3/seclusa-word-puzzle)

## Documentation

**[INSTRUCTIONS.md](INSTRUCTIONS.md)** — how to play every mode, dictionary notes, and privacy.

## Dictionary disclaimer

Every word is from **[ENABLE1](https://en.wikipedia.org/wiki/ENABLE_(word_list))** (**public domain** — not an open-source software licence). Shipped offline in `static/js/words.js` (lengths 2–12; targets use 4–7). Offensive terms removed as far as practicable; please report any that remain.
